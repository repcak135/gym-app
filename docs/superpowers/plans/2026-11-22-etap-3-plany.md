# Etap 3 (Plany) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plans screen (list, active plan, create/rename/copy/delete), plan detail with days, day detail with exercises (sets, warm-ups, rep range, rest, reorder), Start screen showing the active plan's next day.

**Architecture:** All plan logic in `src/data/plans.ts` (pure functions on `Plan` + thin Dexie wrappers), UI pages read via `useLiveQuery`. No schema change: `plans: 'id'` table and `Plan/PlanDay/PlanItem` types already exist in `src/data/types.ts`; active plan in `AppSettings.activePlanId` (`src/data/settings.ts`).

**Tech Stack:** React 19, react-router 8 (HashRouter), Dexie 4 + dexie-react-hooks, lucide-react, Vitest + fake-indexeddb, Playwright (project `mobile`, iPhone 13).

**Spec:** `docs/superpowers/specs/2026-11-22-gym-app-design.md` (sections "2. Plany", "Ustalenia po przeglądzie", "Etapy")

## Global Constraints

- Polish UI; exercise names in English (from the DB).
- Dark tokens from `src/theme/tokens.css`; touch targets ≥ 44 px; floating bottom nav must not cover the last row.
- Data only on the phone (Dexie); all plan logic in `src/data/`.
- Defaults for a new item: `sets 3, warmupSets 0, repsMin 8, repsMax 12, restSec 120`.
- Rest picker values: 0:30 … 5:00 in 15 s steps, displayed `m:ss`.
- Entering ~30 exercises must be quick: picker stays open for multi-add (tap = add + toast "Dodano"), new items get the previous item's settings in that day.

## Review Focus

- Deleting the active plan → `activePlanId` cleared, Start shows "Brak aktywnego planu".
- First plan created → becomes active automatically.
- repsMin > repsMax typed → saved clamped (`repsMax = max(repsMin, repsMax)`).
- Item whose exercise was deleted/missing → row shows "Nieznane ćwiczenie", still removable.
- Day with 0 exercises / plan with 0 days → empty-state text, no crash; next-day = first day.

### Task 1: Data layer `src/data/plans.ts`

**Files:** Create `src/data/plans.ts`, `src/data/plans.test.ts`

**Interfaces (Produces):**
- `createPlan(name: string): Promise<Plan>` — trims, rejects empty ("Podaj nazwę"), `startedAt` = today `YYYY-MM-DD`, `days: []`; sets active if no active plan.
- `renamePlan(id, name)`, `copyPlan(id): Promise<Plan>` (name + " (kopia)", new ids for plan and days), `deletePlan(id)` (clears `activePlanId` if it pointed there), `setActivePlan(id)`.
- `addDay(planId, name): Promise<PlanDay>`, `renameDay(planId, dayId, name)`, `moveDay(planId, dayId, dir: -1|1)`, `deleteDay(planId, dayId)`.
- `addItems(planId, dayId, exerciseIds: string[])` (defaults or copy of last item's settings), `updateItem(planId, dayId, index, patch: Partial<PlanItem>)` (clamps: sets 1–20, warmup 0–10, reps ≥1, repsMax ≥ repsMin), `moveItem(planId, dayId, from, to)`, `removeItem(planId, dayId, index)`.
- Pure helpers: `moveInArray<T>(arr, from, to): T[]`, `formatRest(sec): string` (`120 → "2:00"`), `formatReps(item)` (`"10–12"` or `"10"` when equal), `nextDay(plan, lastDayId?: string): PlanDay | undefined` (day after last workout's `dayId` for this plan, wrap; first day if none).
- `getLastPlanDayId(planId): Promise<string | undefined>` — newest `workouts` row with that `planId`.

- [ ] Tests: create→active; delete active clears setting; copy gets new ids; moveDay/moveItem order; updateItem clamping; formatRest(90)="1:30"; nextDay wraps; addItems copies last item settings.
- [ ] Implement; `npx vitest run` green; commit.
