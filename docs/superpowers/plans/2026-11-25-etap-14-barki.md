# Etap 14 — barki: przód, bok, tył — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split "Barki" into three heads (przód / bok / tył) for built-in shoulder exercises and use it in the Mięśnie filter, swap ranking, sets-per-muscle stats, body map and exercise chips. Unknown stays plain "Barki".

**Architecture:** Optional field `Exercise.delts` computed by a pure rule classifier (`src/data/deltHeads.ts`) + manual override JSON, applied by `fromDb` on reseed (exercise DB version 6). No Dexie schema change; user data (history, notes, custom exercises) untouched. Custom exercises get heads only when the user picks them in the form.

**Tech Stack:** React 19, TS, Dexie, Vitest, Playwright.

**Spec:** request from the parent session (2026-11-24) + design doc.

## Global Constraints

- Existing stats/filters must work for exercises without `delts` exactly as now ("Barki").
- Polish labels: `Barki — przód`, `Barki — bok`, `Barki — tył` (chips/filter options), short forms `przód`, `bok`, `tył` inside the Barki filter/stats.
- Reseed (version 6) keeps weightStep/barWeight/measureOverride and remaps nothing; migration test proves history, notes, plans and custom exercises are unchanged.
- Release: next 0.9.x + Polish changelog entry.

## Review Focus

- Exercise with shoulders only as SECONDARY (e.g. incline bench): heads go to `secondary`, never makes it a "shoulder exercise" in the filter's primary sense beyond what the current filter does (current filter matches primary OR secondary).
- Name containing both "rear" and "lateral" (e.g. "Rear Lateral Raise") → rear, not side.
- "Upright row" → side primary, front secondary; traps untouched.
- Custom exercise with "shoulders" and no heads → shown as plain "Barki" everywhere, filter "Barki" (all) still finds it; head sub-filter does not.
- Body map with a mix of known and unknown shoulder exercises: unknown keep lighting both front and back deltoids.

### Task 1: Classifier, data, migration

**Files:** Create `src/data/deltHeads.ts` (+ test), `src/data/delt-overrides.json`. Modify `src/data/types.ts`, `src/data/exercises.ts` (`fromDb`, `EXERCISE_DB_VERSION = 6`), `src/data/exerciseLabels.ts`, `src/data/exerciseShare.ts` (optional field for custom), tests.

**Interfaces:**
```ts
export type DeltHead = 'front' | 'side' | 'rear';
export interface Delts { primary: DeltHead[]; secondary: DeltHead[] }
// Exercise += delts?: Delts
export function classifyDelts(ex: Pick<Exercise, 'id' | 'name' | 'equipment' | 'primaryMuscles' | 'secondaryMuscles'>): Delts | undefined;
export const DELT_LABEL: Record<DeltHead, string>; // przód, bok, tył
export function deltChipLabel(h: DeltHead): string;  // "Barki — przód"
export function deltHeadsOf(ex: Pick<Exercise,'delts'>, role?: 'primary' | 'secondary' | 'any'): DeltHead[];
```
Rules (`name` lowercased; only when "shoulders" is in primary or secondary muscles, or a rear-delt pattern matches; first match wins; role = primary if "shoulders" ∈ primaryMuscles else secondary):
1. Overrides JSON by id (`null` = leave unclassified).
2. rear: /rear delt|reverse fly|reverse flye|reverse pec ?deck|face ?pull|bent[- ]over (lateral|dumbbell )?raise|rear lateral|prone y|y[- ]raise|band pull[- ]apart|seated bent-over/ → `{primary:['rear'], secondary:[]}`.
3. side: /lateral raise|side raise|side lateral|lateral delt|cable lateral|lean[- ]away lateral|upright row|l[- ]raise/ → side primary; upright row also front secondary.
4. front: /front raise|front plate raise|front delt/ → front primary.
5. presses overhead: /overhead press|shoulder press|military press|arnold|push press|seated (dumbbell|barbell) press|landmine press|handstand push|pike push/ → front primary, side secondary (Arnold: front + side primary).
6. horizontal/incline presses & dips where shoulders listed: /bench press|incline|push-?up|dip|chest press|fly(e)?s?\b/ (not "reverse") → front secondary (role forced to secondary).
7. rows/pulls where shoulders listed: /row|pull/ → rear secondary.
8. else undefined.
- Overrides file starts with the cases the rules get wrong in a review: run the classifier over the whole catalogue, list every exercise with shoulders in primary muscles and the result, review the unclassified and suspicious ones (by name), and add overrides; commit the review list as `docs/delt-heads-review.md` (id, name, result).

Migration test: DB at version 5 with history/notes/plan/custom exercise → seed v6 → all user rows equal, built-in Side_Lateral_Raise has delts side. Commit `feat: deltoid heads classifier and catalogue v6`.
